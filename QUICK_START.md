# Quick Start (VS Code)

1. Extract the ZIP file.
2. Open VS Code.
3. Select **File → Open Folder** and choose `Digital_Library_Search_and_Book_Recommendation`.
4. Select **Terminal → New Terminal**.
5. Run `python main.py` (Windows alternative: `py main.py`).
6. To run tests, use `python -m unittest discover -s tests -v`.

The project uses only Python's standard library; no `pip install` step is needed.
